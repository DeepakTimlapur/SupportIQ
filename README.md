# SupportIQ
## AI-Powered Customer Support Intelligence

An AI-powered customer support assistant using Retrieval-Augmented Generation.

### Technology Stack
- Python
- FastAPI
- Streamlit
- RAG
- Sentence Transformers
- ChromaDB
- LLM
- Pytest

### Objective
Build a reliable customer support assistant that provides
source-grounded answers, integrates order services,
detects unsafe requests and escalates uncertain cases.
